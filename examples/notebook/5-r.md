# R cells, run in your browser

A cell written in an `r` fence **runs** here, with [go-embedded-r](https://go-embedded-r.github.io/)'s evaluator compiled to WebAssembly. There is no external `R` behind it, and no server. The badge on the cell says **R**, and the output is what R prints.

R's variables persist from one R cell to the next. This cell defines a function and some data:

```r
square <- function(v) v^2
xs <- square(seq_len(10))
```

The next R cell reads them. Its last value is printed as R prints it, and `cat` and `message` write where R writes them:

```r
total <- sum(xs)
total
cat("mean of the squares:", mean(xs), "\n")
summary_of <- c(min = min(xs), max = max(xs), spread = max(xs) - min(xs))
summary_of
```

A warning comes the way R gives it, after the output of the cell:

```r
ratio <- function(a, b) {
  if (b == 0) warning("division by zero")
  a / b
}
ratio(1, 0)
```

R's variables **stay R's**, as in go-notebook: they do not cross to the Go cells, and the Go cells' variables do not cross to R. This Go cell has its own `total`, and the R cell above is not touched by it:

```go
total := 42
total
```

An error is R's own, `Error in call : message`, and stops the run, as in every language. This notebook would stop being published if one of its cells failed, so here is one, quoted. With a cell that reads

> sqrt("a")

the page shows `Error in sqrt("a") : non-numeric argument to mathematical function`, and the cells after it say they were not run. Try it: add an R cell with `sqrt("a")` and run the notebook.

## Limits

A browser tab must not run out of memory or freeze, so an R cell is bounded: 512 MiB of vector storage, 20 million calls and loop iterations, and 10 seconds. A cell that goes past one is stopped with a message that says which, and the page stays usable: `while (TRUE) 0` ends on the step limit. The files a cell writes live in a private in-memory tree, and the environment is empty: no file or variable of your machine is visible to it.

What is not here yet: packages (`library`), graphics, and linear algebra (`solve`, `qr`). The output is text. Follow the progress at [go-embedded-r.github.io](https://go-embedded-r.github.io/).
