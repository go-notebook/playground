# C cells, checked but not run yet

A cell written in a `c` fence is **parsed and checked** with [go-embedded-c](https://github.com/go-embedded-c/c)'s front end, and it is **not run**: go-embedded-c has no code generation yet (its milestone M2). Until that lands, a C cell is checked, not run. No C compiler is started, in this page or anywhere. The badge on the cell says so: *C · not runnable yet*.

C cells are not independent, as they are in a C file: a cell sees the typedefs, macros and declarations of the C cells before it. The first one below declares a type and a size; the second one uses both, and would be an error alone.

```c
typedef int myint;
#define N 10
```

This C cell is well formed, so it is not an error. It does not run either: its output says why, and no number comes back. Only variables cross to the other languages. Functions, typedefs and macros stay C's, so `total` is the one name a Go cell can read.

```c
myint total = N * N;
```

Go draws the size, and this Go cell reads `total`, which the C cell defines. The name analysis sees that, so the cell is **blocked**: it waits for the C cell, and says so, instead of failing on a name that never arrives.

```go
m := total + 1
```

A cell that does not read anything from C is not held back. It runs as usual, whatever the C cells above it do:

```go
n := 10
n * 2
```

A mistake in a C cell is caught at the right line, before anything runs, in the front end's own words, and the cells that do not read it still run. This notebook would stop being published if one of its cells had one, so here is one, quoted. With a cell that reads

> int y = 2;
> int x = y y;

the page shows `line 2:11: unexpected identifier, expected ';'`, at line 2, column 11, where a second name follows the first with no operator between them. Try it: add a C cell with `int x = y y;` and run the notebook.

When go-embedded-c's code generation lands, these cells will run and the blocked cell will compute `total + 1`. Follow the progress at [github.com/go-embedded-c/c](https://github.com/go-embedded-c/c).
